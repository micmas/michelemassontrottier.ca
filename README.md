# michelemassontrottier.ca

Source code of [michelemassontrottier.ca](https://michelemassontrottier.ca), built with [Astro](https://astro.build) and published with GitHub Pages.

Content is written in Markdown (`src/content/`), in French and English. Every push to `main` rebuilds and publishes the site.

```bash
npm install
npm run dev   # local preview at http://localhost:4321
```
